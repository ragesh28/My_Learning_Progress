# My Learning Progress — DSA & AI

🌐 **Live Website:** [https://ragesh28.github.io/My_Learning_Progress/](https://ragesh28.github.io/My_Learning_Progress/)

An interactive web application built to track my learning progress across **Data Structures & Algorithms (DSA)** and **Artificial Intelligence (AI)** — combining visual intuition, a structured Python interview roadmap, interactive knowledge trees, and study notes in one place.

## Sections

### 1. DSA Home
- **Integrated Learning Philosophy:** Learn data structures, algorithms, and algorithmic techniques together in logical prerequisite chains (`Array → Linear Search → Sorting → Binary Search → Two Pointers → Sliding Window`, etc.).
- **Data Structure Classifications:** Real-world examples and use cases across Linear, Associative, and Non-Linear structures, plus clear distinctions between data structures, algorithms, and techniques.
- **Interactive Search Showdown:** Step-by-step animated comparison of Linear Search vs. Binary Search (splitting-tree visualization) showing why `O(log n)` dramatically outperforms `O(n)`.
- **Time & Space Complexity Guide:** Everyday analogies for `O(1)`, `O(log n)`, `O(n)`, `O(n log n)`, `O(n²)`, and `O(2ⁿ)`.

### 2. Learn DSA (Progress Tracker)
- **6-Phase Roadmap (57 Topics):** Ordered from Beginner to Advanced with interactive completion tracking and concept breakdowns.
- **Immediate 13-Step Checklist & DP Order:** Focused starting path and 12-step Dynamic Programming progression.
- **Pattern Recognition Table:** Searchable quick-reference mapping problem clues to the right technique.
- **150-Problem Practice Plan & 8-Step Mastery:** Topic-wise solved problem counters (30% Easy / 60% Medium / 10% Hard) and a repeatable 8-step mastery workflow.

### 3. Deep DSA (Interactive Knowledge Trees)
- **Data Structures Tree:** Collapsible tree covering Linear, Associative, and Non-Linear structures.
- **Algorithm Techniques Tree:** Collapsible tree mapping each technique to compatible data structures, sub-techniques, and concrete algorithms.
- **Search, Filter & Free Animations:** Filter by keyword or difficulty and launch curated free algorithm animation websites for each topic, alongside topic study notes.

### 4. AI Hub
- Structured space for tracking AI study notes, research papers, links, categories (Papers, LLMs, Agents, RAG, ML Foundations), tags, and reading status.

- Vite 6
